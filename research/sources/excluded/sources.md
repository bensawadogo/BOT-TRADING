|--------|----------|

## 🔴 Repos sans backing

| Raison | Exemples |
|--------|----------|
| Pas de README crédible | Repos "ai-trading-bot" sans doc |
| Pas d'activité (>12 mois) | Repos abandonnés |
| Pas de tests ni données | Repos avec seulement un main.py |
